### React performance case study

A technical case study based on optimizing a large React/Redux application from render chaos to a significantly faster UI.

**Topics covered:**

* React rendering bottlenecks
* Selector instability
* Global state update propagation
* Large table performance
* WebSocket update batching
* Moving expensive work out of render
* CSS containment and rendering isolation

**Result:** key user interactions became approximately **3x faster**.

[Article](https://medium.com/@dmitriilobanov3/optimizing-a-large-react-redux-app-from-render-chaos-to-a-3x-faster-ui-9d6b2038eb05)
